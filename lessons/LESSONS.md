## 🐝 2026 Offseason: Rebuild the 2026 Robot

This offseason, the robot half of each lesson programs a piece of **last season's robot**. Lesson by lesson you rewrite the code the team competed with, until you've put the whole robot together yourself.

- **Start with [Lesson 00](./LESSON00.md).** It sets up your fork and the simulator.
- **Aim for 2 lessons a week**: the Java half first, then the robot half. Points earned by **kickoff** count toward the prize.
- **Follow the Core path.** *Optional* lessons don't build a piece of the robot, so skip them unless you're ahead.
- **Code Archaeology is optional.** Do it when you have time.
- **2026 Robot Half** shows which robot exercises are rewritten for the 2026 robot. The rest are on the way.
- Robot facts (CAN IDs, buttons, speeds): [ROBOT.md](../robot-code/command-based-bot-2026/ROBOT.md)
- **Not sure if your simulator works?** Set `LESSON = 98` for the simulator check, a working demo you can drive. Real lessons start as empty files, so publishing nothing is normal.

## 📌 Lesson Status Key

- **[IDEA]** – Placeholder for a lesson that’s planned but not yet started.  
- **[AI_SLOB]** – Draft auto‑generated from AI transcription of a YouTube video. Expect rough edges, missing context, and no test data yet.  
- **[DRAFT]** – A first pass written/edited by me, but not yet tied into robot examples or exercises.  
- **[WORK IN PROGRESS]** – Currently being refined with robot‑specific connections, examples, and exercises.  
- **[READY FOR REVIEW]** – Lesson looks complete, but still needs testing or peer review before being finalized.  
- **[COMPLETE]** – Fully reviewed, polished, connected to robot code, and includes test data for practice.  
- **[NEEDS UPDATE]** – Lesson was once complete but is now outdated (e.g., new Java version, FRC library changes, or better examples needed).
